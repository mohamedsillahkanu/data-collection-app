# HF01 Monthly Summary Outpatient Morbidity - Complete Computation Mapping

## Overview

This document provides the **exact variable names** and **computation logic** for the HF01 Monthly Summary form used in Sierra Leone's Health Information System. The summary is generated by aggregating data from two source registers:

1. **UNDER_FIVE_REGISTER** - For children 0-59 months (under 5 years)
2. **GENERAL_REGISTER** - For patients 5 years and above

---

## Form Header Variables

| Variable Name | Label | Source |
|---------------|-------|--------|
| `year` | Year | Form input (report period) |
| `month` | Month | Form input (report period) |
| `healthFacility` | Health Facility Name and Type | Form input |
| `facility_type` | Facility Type | Form input |
| `chiefdom` | Chiefdom | Cascading data lookup |
| `district` | District | Cascading data lookup |
| `region` | Region | Cascading data lookup |
| `generated_date` | Date form generated | System timestamp |

## SECTION 1: MALARIA (Left Panel - Facility Morbidity Cases)

### Age Group Columns for Malaria Section
- **Col 3**: 0-59 m (from UNDER_FIVE_REGISTER)
- **Col 4**: 5-14 yrs (from GENERAL_REGISTER where age_years >= 5 AND age_years <= 14)
- **Col 5**: 15+ yrs (from GENERAL_REGISTER where age_years >= 15)
- **Col 6**: Referral (count of referrals)

## Notes

1. **Sex Disaggregation**: Most malaria and child health indicators require separate counts for Male (suffix `_m`) and Female (suffix `_f`)

2. **Age Groups**: Different sections use different age groupings as shown in the column headers

3. **Form Structure**: The HF01 form has a two-panel layout:
   - Left panel: Facility morbidity cases (Malaria, STI, Mental Health, NTD, Others)
   - Right panel: Child health, Child mortality, Adult mortality, Neonatal, Clinic attendance, FHC, GBV

4. **Data Sources**: Some indicators combine data from both registers (e.g., worm_infestation, eye_infection, trauma)

5. **Referrals**: Referral columns appear in the malaria section and are computed separately for each age group
